# Calculadora

Calculadora desenvolvida em Java como um dos meus primeiros projetos pessoais.

## Sobre o projeto

Este projeto foi desenvolvido para praticar conceitos de Java e Programação Orientada a Objetos, além da criação de interfaces gráficas com Swing.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Porcentagem
- Raiz quadrada
- Números decimais
- Interface gráfica com Swing

## Tecnologias

- Java
- Java Swing
- Eclipse

## Objetivo

Este é um dos meus primeiros projetos desenvolvidos durante meus estudos de Java no NANOCUSER da FIAP e vídeos por fora. O objetivo principal foi colocar em prática conceitos de programação, orientação a objetos, eventos e organização do código em diferentes classes.
